# common-tpa

Plugin de TPA para Paper.

## Comandos

- `/tpa <nick>`: pede para teleportar até o jogador.
- `/tpahere <nick>` ou `/tpa here <nick>`: pede para trazer o jogador até você.
- `/tpa <nick> accept|deny`: aceita ou nega o pedido de TPA daquele jogador.
- `/tpa here <nick> accept|deny` ou `/tpahere <nick> accept|deny`: aceita ou nega o pedido de TPA aqui daquele jogador.

Os nicks de jogadores online são sugeridos durante a digitação. Um jogador pode receber pedidos de várias pessoas ao mesmo tempo e responder a cada um individualmente.
